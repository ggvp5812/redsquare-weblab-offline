# Red Square Web Lab — Offline Edition

Столкнулся с проблемой: купил новую клавиатуру, а софта под неё нет — настраивается исключительно через веб-сайт `conf.red-square.org`. Чтобы не зависеть от интернета и серверов компании, с помощью ИИ полностью задампил веб-версию конфигуратора и собрал в один автономный офлайн-бинарник.

### Тестирование
Успешно проверено на клавиатурах:
- **Red Square Alumix TKL SE G3ms Sapphire (RSQ-20063)**
- **Red Square Alumix TKL Classic Kitsune (RSQ-20051)**

Все остальные модели из веб-конфигуратора также должны работать штатно.

---

## Как использовать
1. Перейдите в раздел [Releases](../../releases) и скачайте **`RedSquareConfig.exe`**.
2. Запустите файл на компьютере (откроется консоль и автоматически поднимется сайт в браузере).
3. Нажмите кнопку **«Подключить»** и выберите клавиатуру в списке.
4. После настройки просто закройте окно программы.

> **Примечание:** Для работы с клавиатурой используйте браузер на движке Chromium (**Google Chrome**, **Microsoft Edge**, и предположительно другие браузеры на базе Chromium тоже будут работать). Firefox технологию WebHID не поддерживает.

---

## Сборка из исходников
Если хотите собрать бинарник самостоятельно (нужен Go 1.16+):

```bash
go install github.com/akavel/rsrc@latest
~/go/bin/rsrc -ico app.ico -arch amd64 -o rsrc_windows_amd64.syso
GOOS=windows GOARCH=amd64 go build -ldflags="-s -w" -o RedSquareConfig.exe
```
